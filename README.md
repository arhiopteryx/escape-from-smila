# Escape from Сміла

Браузерна top-down аркада про кур’єрський рейд, VR-кафе та пригоди героя. Інтерфейс гри — українською. Проєкт розрахований на ПК; сенсорного керування немає.

## Запуск

Відкрий `index.html` у сучасному браузері. Зовнішні залежності та локальний сервер для запуску не потрібні. Після змін у вихідному коді створи новий `game.js` командою:

```sh
node scripts/build-game.mjs
```

## Керування на ПК

- **WASD** або **стрілки** — рух.
- **Space** — ривок або дія рівня; утримання стріляє сирниками там, де це потрібно.
- **E / F / Enter** — взяти, подати або виконати поточну взаємодію.
- **Shift** — ривок у VR та лісі.
- **Esc** — пауза; **⛶** — повноекранний режим.
- У кафе можна натиснути ліву кнопку миші для взаємодії. У VR-аркаді клік по ігровому полю стріляє.

У меню є прямий вибір глав. Кнопка **«Продовжити»** повертає до початку останньої вибраної глави. Зберігається номер глави, не стан усередині рівня; це працює через `localStorage` браузера.

## Зміни в механіках

- Кур’єрський маршрут малюється по сітці вулиць і показує напрямок та відстань до цілі.
- Нічний бус рухається маршрутом через перехрестя; пішоходи розбігаються від нього.
- У кафе підсвічується столик, який чекає на вибрану страву. Помилкова подача не забирає страву; її можна повернути на кухню.
- У санвузлі та лісі утримання E і Space більше не скидається опитуванням геймпада. У санвузол одночасно можуть заходити до трьох військових; для завершення потрібно сім візитів.
- Сліди в кукурудзяному полі залишаються видимими довше.
- На VR-заводі підсвічується актуальна ціль.
- На мапі Німеччини видно пляшки, суперників і поточну ціль. E поруч із суперником ненадовго відволікає його.

## Структура

- `index.html` — ігрова розмітка та HUD.
- `styles.css` — оформлення й адаптивне меню.
- `js/01-runtime.js` — спільний ігровий світ, стан, прогрес і утиліти.
- `js/02-early-levels.js` — нічна погоня, VR-завод і ліс.
- `js/03-germany.js` — німецький рівень.
- `js/04-chase.js` — сцена захоплення та логіка погоні.
- `js/05-courier-cafe.js` — доставка, місто та VR-кафе.
- `js/06-training.js` — санвузол і кукурудзяне поле.
- `js/07-engine.js` — рендеринг, мапи та цикл гри.
- `js/08-controls.js` — клавіатура, геймпад і дії мишею.
- `scripts/build-game.mjs` — збирає вихідні частини в файл для запуску.
- `game.js` — зібрана браузерна версія.
- `assets/` — логотипи гри.

Збірка зберігає логіку в окремих вихідних файлах і поєднує їх у спільний runtime для запуску через `file://`. Звукові ефекти поки створюються Web Audio API; музику й художні спрайти доробимо окремо.
