# Escape from Сміла

Браузерна top-down аркада про кур’єрський рейд, VR-кафе та пригоди героя. Інтерфейс і тексти гри — українською.

## Запуск

Відкрий `index.html` у сучасному браузері. Збірка, сервер і зовнішні залежності не потрібні.

## Керування

- **WASD** або **стрілки** — рух.
- **Space** — ривок/дія відповідно до рівня.
- **E / F / Enter / клік** — взаємодія у кафе та навчальному центрі.
- **Esc** — пауза.
- У браузерах із підтримкою Fullscreen — кнопка ⛶ розгортає ігрове поле.

На сенсорних екранах з’являється екранний контролер.

## Структура

- `index.html` — розмітка та HUD.
- `styles.css` — оформлення, адаптивне меню й стани фокусу.
- `js/01-runtime.js` — глобальний стан та базові утиліти.
- `js/02-early-levels.js` — погоня, VR-бій і ліс.
- `js/03-germany.js` — німецький рівень.
- `js/04-chase.js` — катсцена захоплення й логіка погоні.
- `js/05-courier-cafe.js` — доставка, міська сцена та VR-кафе.
- `js/06-training.js` — навчальний центр і кукурудзяне поле.
- `js/07-engine.js` — рендеринг, мапа та цикл гри.
- `js/08-controls.js` — клавіатура, геймпад і UI.
- `game.js` — зібраний браузерний файл, який підключає `index.html`.
- `scripts/build-game.mjs` — збирає вихідні частини в `game.js`.
- `assets/` — логотипи й графічні ресурси кампанії.

Після змін у вихідних частинах виконай `node scripts/build-game.mjs`. Зібраний файл уже є в репозиторії, тому гру можна запускати відкриттям `index.html` через `file://`, без сервера та без кроку збірки.

Звукові ефекти створюються Web Audio API у браузері; зовнішні аудіофайли не потрібні.
